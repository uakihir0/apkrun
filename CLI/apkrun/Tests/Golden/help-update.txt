OVERVIEW: Check for, list, and manage Android app updates.

USAGE: apkrun update [<package>] [--file <file> ...] [--check-only] [--now] [--json] <subcommand>

ARGUMENTS:
  <package>               The Android package name. Omit it to check every
                          package.

OPTIONS:
  --file <file>           APK files for a manual update.
  --check-only            Report only; do not download or notify.
  --now                   End the running app and install now (§7.3 Update Now).
  --json                  Print the results as JSON.
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  policy                  Set the update mode and provider of an Android app.
  authority               Set the update authority of an Android app.
  history                 Show the update history of Android apps.
  skip                    Skip an update version so it is not offered again.
  unskip                  Offer a skipped update version again.

  See 'apkrun help update <subcommand>' for detailed help.
