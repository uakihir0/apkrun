OVERVIEW: Run Android apps as Mac apps.

USAGE: apkrun <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  version                 Show APKRun version information.
  logs                    Read APKRun host logs.
  dev                     Run development-only APKRun commands.

  See 'apkrun help <subcommand>' for detailed help.
