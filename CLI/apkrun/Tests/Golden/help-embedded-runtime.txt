OVERVIEW: Run Android apps as Mac apps.

USAGE: apkrun <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  version                 Show APKRun version information.
  runtime                 Inspect and control the Android runtime.
  logs                    Read APKRun host logs.
  install                 Inspect and install one APK or a set of APK splits.
  uninstall               Remove an installed Android app.
  rollback                Roll an app back to its previous version.
  repair                  Reinstall a broken app from APKRun's retained APKs.
  list                    List installed Android apps.
  info                    Show runtime status or details for one Android app.
  launch                  Launch an installed Android app.
  stop                    Stop an Android app session.
  integrations            Inspect desktop integrations of an Android app.
  shared-folders          List, add, and remove folders shared with Android
  update                  Check for, list, and manage Android app updates.
  config                  Read and write daemon settings.
  dev                     Run development-only APKRun commands.

  See 'apkrun help <subcommand>' for detailed help.
