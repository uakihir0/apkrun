# Open Questions

This file lists everything that is not decided yet. Each question has a working default, so implementation never waits for an answer: build to the default, and change it only when the question is settled. A question that could make a design fail is a risk, not a question. It is in [risks.md](risks.md).

---

## 1. Kinds and rules

| Kind | Meaning | Who settles it |
|---|---|---|
| **Decision** | A choice for the project owner. No test can answer it. | The project owner, before the deadline task starts |
| **Verification** | A fact about macOS, Android, or a library that a task finds out. The design covers both outcomes. | The task named in the deadline column |
| **Deferred** | A feature idea kept out of v1 on purpose. It is not planned. | Reopened after v1.0 (or in v1.x) through a new task |

- IDs are permanent. A new question takes a number that no row uses.
- **Status:** `open`; `settled` (the outcome is in the row, and the design documents that name the default are updated in the same pull request); `deferred`.
- A Decision still open when its deadline task starts blocks that task. Raise it at the milestone review ([roadmap.md](roadmap.md) §4).
- The scanout hotplug interrupt and the display ID after a mode change are risks: R-01 and R-04 in [risks.md](risks.md).
